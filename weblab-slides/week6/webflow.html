What is Webflow?

Webflow is a visual web design and development platform that lets you design, build, and launch responsive websites without manually writing code, while still generating clean HTML, CSS, and JavaScript behind the scenes.

How does it compare with the other 2 main platforms? (Wix and Squarespace)

  • Webflow: Gives you full control over layout using real CSS concepts.
  • You design visually, but the platform generates structured HTML/CSS/JS.
  • Best when you need precise spacing, breakpoints, animations, or custom layouts..
  • Wix: Easy visual drag-and-drop freedom on a canvas, but the generated CSS is not as clean.
  • Templates are locked once chosen; changing templates requires rebuilding.
  • Squarespace: Section-based editing with a strong design system.
  • Less freedom than Webflow, but layouts stay visually consistent.
  • Template customization is limited.

The webflow interface

The HTML side

  • On the left side, if you click the (+) sign you can add HTML elements to the stage.
  • You will see some familiar names like, section, div, heading, list, paragraph
  • If you click on the stage (the white canvas) and then click on any element it will be added to the body.
  • A new element will be added inside the previously selecte element. If you click on the body and add a section, and then a container, the container will be directly inside the section and not the body because it was the last selected was the section.

The Navigator

  • One of the most important areas to navigate your webflow site is the Navigator. (The 3rd icon on the left side).
  • There you can see the structure of your HTML and can make changes if you need to by dragging and dropping the elements.
  • It's very easy to misplace elements by dropping elements to the stage, the navigator helps us make sure we keep all the elemets in the right place.

The CSS Panel

  • On the right side, you have the tools to add the CSS styles to the elements you have on the stage.
  • Click on an element and you can select any of the familiar styles from the right.
    • color
    • font
    • background
    • margin and padding
    • width and height
    • etc.
