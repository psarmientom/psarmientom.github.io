Centering Content in the Page

Centering content on the page

  • Add a width to the container you want to center. Use % (70 to 85% is a good size) or vw (viewport width proportion)
  • Add auto margin to the left and right to the inside container, and let css calculate the distance.margin: 0 auto;
  • This works for centering a container inside the body tag as well as centering a container inside another one like the example below.

Aligning Images

  • Images by default will display side by side if there is enough horizontal space available because their default display property is inline.

What happens if you add them inside a figure tag or a div?

  • When you add the image inside a figure tag, they lose their inline property, because the figure behaves as a block, so each image will take its own row.
  • Here you have 2 options
    1. add display:inline-block to the figure tag
    2. wrap the 3 images in another container and use flex

Using Inline-Block

  • When using figure you lose the inline property of the image, so each image will take it's own row, so you need to change the display property.
  • When you use inline-block if the elements are not of the same height you can use vertical align (top, middle, bottom).

Using Flex

  • When you use Flex you need to add an additional container wrapping the figure tags.
  • Then change the display property to flex.
  • When you have display flex you have more options.
  • gap is the separation between the elements
  • If you add a width to the parent container then you can position the elements in the horizontal axis.
  • justify-content: will align the eements in the horizontal axis (start, center, end, space-around, space-between)
  • If the height of the container is bigger than the height of the images you can also align the images in the vertical axis using align-items (start,center,end)

What if I want to make all my images the same size?

  • In most cases you have images that have different proportions. The easiest way to have them look the same would be to crop them with the same dimensions. But sometimes this is not possible. In that case we have an option.
  • We need to add the image inside a div or a figure tag. (The below example uses a figure tag).
  • First we add the width and height we want to the figures or divs that contain the images.
  • Then we target the images inside the divs and assign them a height and width of 100% so they fill the whole area.
  • In most cases the proportion is going to be different, so you need to add object-fit (contain, cover, fill)
